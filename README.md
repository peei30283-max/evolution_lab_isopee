## まち感性区分の拡張と、まち情報との関連付け
まち感性区分の定義テーブルの、大区分と中区分のオリジナルデータにおいて、それぞれの区分に情報を追加した上で、まち情報と関連付けをおこなう。  
また、中区分と大区分の関係、中区分と感性セグメント(一般）との関連付けを行ない、まち情報に関連付けられた中区分に対して感性セグメントを紐づけする。  

■ 準備  
OpenAI を利用するアカウントを作成し、APIキーを取得しておく。  
./conf に以下のファイルを作成して APIキーをおく。  
{  
  "OPENAI_API_KEY": "API key"  
}  
  

■ 処理の流れ  
 (1) 大区分、中区分に対して、感性要素例の追加、説明文、関連ワードを追加した拡張テーブルを作成する。概要、感性要素例を参照しつつ、拡張情報を追加する。  
　　　実行プログラム: まち感性_区分テーブルの拡張.ipynb  
    入力ファイル: data/city_image.tsv  
	出力ファイル: data/city_image_extention.tsv  
  
  (2) まち感性区分定義の拡張テーブルを用いて、大区分、中区分の感性要素と説明文を比較し、関連類似度を計算し、中区分に関連性の高い大区分（上位２個）を抽出する。同時に関連判定理由も作成する。  
　　　実行プログラム: 大区分と中区分を関連付ける.ipynb  
    入力ファイル: data/city_image_extention.tsv  
	出力ファイル: result/matching_middle_to_major.tsv  
  
  (3) 中区分の感性要素と説明文と、感性セグメントのラベル名と説明文を比較し、関連類似度を計算し、中区分に関連性の高い感性セグメント（上位3個）を抽出する。同時に関連判定理由も作成する。  
　　　実行プログラム: 中区分と感性セグメントとのマッチング.ipynb  
    入力ファイル1: data/city_image_extention.tsv  
    入力ファイル2: data/kansei_segment_simage.tsv  
	出力ファイル: result/matching_middle_to_segments.tsv  
  
  (4) 「出汐地区」の情報を作成する。情報には、地名由来、歴史、環境、住みやすさ、観光地、特産物、といったその街の特徴が記載されているものとする）  
	例:data/出汐地区情報.txt  
  
  (5) 「出汐地区」の情報に関連性の高い中区分（上位２個）を抽出する 
  中区分の感性要素と説明文、関連ワードと、「出汐地区」の情報の内容を比較し、類似度を計算し、類似度の高い2個を抽出する。同時に類似判定理由も作成する。  
  関連性の高い中区分に対して、関連性の高い感性セグメントを類似度(スコアー値)と、類似判定理由を付与する。  
　　　実行プログラム: 出汐地区のまち情報と感性_中区分の関連付け.ipynb  
    入力ファイル1: data/city_image_extention.tsv  
	出力ファイル: result/matching_city_to_middle.tsv  
  
  (6) 「出汐地区」の情報に関連性の高い感性セグメントを抽出する  
  (5)で抽出した「出汐地区」の情報に関連性の高い中区分に対して、(3) で作成された情報を用いて関連性の高い感性セグメントを付与する。スコアー値は(3)と(5)のスコアー値をかけ合わせた値としている。  
　　　 実行プログラム: 出汐地区のまち情報と感性セグメントとの関連付け.ipynb  
    入力ファイル1: result/matching_city_to_middle.tsv  
    入力ファイル2: result/matching_middle_to_segments.tsv  
	出力ファイル: result/matching_city_to_kansei_segments.tsv
