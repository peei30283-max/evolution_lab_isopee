## まち感性区分の拡張と、まち情報との関連付け
まち感性区分の定義テーブルの、大区分と中区分のオリジナルデータにおいて、それぞれの区分に情報を追加した上で、まち情報と関連付けをおこなう。  
また、中区分と大区分の関係、中区分と感性セグメント(一般）との関連付けを行ない、まち情報に関連付けられた中区分に対して感性セグメントを紐づけする。  

■ 処理の流れ  
 (1) 大区分、中区分に対して、感性要素例の追加、説明文、関連ワードを追加した拡張テーブルを作成する。概要、感性要素例を参照しつつ、拡張情報を追加する。  
　　　実行プログラム: まち感性_区分テーブルの拡張.ipynb  
    入力ファイル: data/city_image.tsv  
	出力ファイル: data/city_image_extention.tsv
