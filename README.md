## 大規模言語モデルを用いた戦術FSM生成と共進化的最適化による捕食者–群れ戦術の自動設計
### 捕食者と群れがAI が作る“進化する戦術”で戦う世界
### ■ 捕食者 vs 群れシミュレーション
２体の捕食者 と 100個体の被食者 が 閉ざされた２次元の空間内で、生存競争をおこなう群れシミュレーションを実行
- 捕食者と被食者はこの空間の外には出ない
- 捕食者と被食者との距離が一定値以下になったときに、捕食さ れたとみなす
  
２体の捕食者は囲い込み、挟み込み、包囲など協調して追跡し、100個体の被食者は集結、散開、回避などの戦術を用いて逃走する生存競争を繰り広げる

### ■ Boidモデル + FSM（有限ステートマシーン）
Boids は、エージェント（＝FSM が選択した行動モードに従って動く個体）の連続的な運動を生成する下層モデル  
FSM が定義する戦術構造（＝行動モード＋遷移＋Boids 重み）は、Boids の力の調整を通じて具体的な運動として実現される  
  
捕食者と被食者は 別々の FSM（＝戦術構造） を持ち、捕食者には 探索・追跡・包囲といった攻撃行動モード、被食者には 散開・回避・逃走といった生存行動モードが定義されており、これらの行動モードは 距離や密度といった遷移条件で切り替わる  
  
この「FSM（意思決定） × Boids（運動生成）」の2層構造により、自然な群れ運動と戦術的な意思決定が同時に成立し、リアルな生態系行動が実現される

#### ■ FSM(有限ステートマシーン) の状態 (=行動モード)
行動モードは FSM の固定プリミティブ 
（探索空間爆発を防ぐため固定）

進化するのはモードの意味 
-- Boids 重み / 遷移条件 / 役割との組み合わせ / 使われ方（どの状況で発火するか）

● LLM：行動モードの構造的な使い方を生成 
（遷移・重み・役割の組み合わせ）

● GA：行動パラメータを最適化 
（Boids 重み・遷移条件・役割条件）

● 名前はラベルにすぎない 
→ 行動の意味は GA/LLM によって世代ごとに進化する
